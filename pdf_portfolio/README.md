# PDF Portfolio Workspace

PDF 포트폴리오 작업물과 조사 자료를 모아둔 폴더입니다.

## Folders

- `current/`: 현재 편집 중인 HTML 원본과 PDF용 이미지 프레임
- `exports/`: 출력된 PDF 파일들
- `renders/`: PDF 검수용 페이지별 PNG 렌더
- `research/`: 포트폴리오 구성 조사/근거 문서
- `source/`: 기존 이력서/포트폴리오 PDF 원본
- `tools/gif/`: GIF 생성 스크립트와 작업 CSV
