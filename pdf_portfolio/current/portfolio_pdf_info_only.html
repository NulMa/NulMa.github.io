Root Cause

  • GameManager.instance에 상태, 입력, UI, 저장 책임 집중.
  • Weapon.Update() switch 분기로 무기 확장 비용 증가.

Fix / Decision

  • Legacy 구조는 비교 기준으로 보존.
  • DOTS gameplay assembly와 외부 서비스 의존성 분리.
  • RenderMeshIndirect는 URP 2D 궁합 문제로 제외.
