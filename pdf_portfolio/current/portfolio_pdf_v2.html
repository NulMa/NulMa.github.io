Ghost March

UnityC#ShaderLabGoogle PlaySolo

공모전 수상 후 Play Store에 출시한 모바일 액션 게임. 출시 이후 Legacy 구조를 기준본으로 보존하고 DOTS 구조를 실험했습니다.

Play Store Gameplay

Problem

  • GameManager.instance가 상태, 입력, UI, 저장을 폭넓게 소유.
  • Weapon.Update() switch 기반 무기 분기로 확장 비용 증가.
  • 대량 적, 데미지 텍스트, UI Toolkit 갱신으로 프레임 비용 증가.

Action

  • Legacy MonoBehaviour 구조를 비교 기준으로 격리.
  • Enemy, Bullet, Drop, Wave, Damage Event를 DOTS 수직 슬라이스로 재구현.
  • MonoBehaviour는 UI, 입력, 씬 부트스트랩, 외부 서비스 연동으로 제한.
9 fpsLegacy 1500 enemies
67 fpsDOTS 4096 enemies
109.5ms -> 14.92msCPU frame time

Workflow

AI Workflow

AI를 단순 코드 생성 도구로 쓰지 않습니다. 역할, 파일 소유권, 테스트, 검증 루프를 먼저 정하고 작업시킵니다.

Operating Rules

  • 넓은 단위 작업은 Codex, 좁은 범위 검증은 Claude Code로 분리.
  • Unity MCP를 연결해 에디터 상태 확인과 검증을 작업 흐름에 포함.
  • scene, prefab, SO, localization table은 단일 소유 원칙 적용.

Review Loop

  • 기능 테스트와 실제 화면 QA를 별도 체크.
  • architecture scan, path guard, git diff check, merge preview 기록.
  • 문서와 구현 상태가 어긋나면 문서 동기화를 별도 작업으로 분리.

Communication

  • 회의가 멈췄을 때 먼저 안건을 정리하고 역할을 나눔.
  • 영상 팀에는 콘티, 대본 팀에는 첫 문안을 제공해 진입 장벽을 낮춤.

MyTokenMate

  • AI coding tool 사용량을 작업 중 확인하기 위한 Electron overlay.
  • raw token보다 rate limit event와 statusLine cache를 우선 표시.
