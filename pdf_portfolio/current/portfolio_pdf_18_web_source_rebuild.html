Legacy to DOTS

Ghost March / Performance Record

Legacy 구조와 DOTS 구조 비교

9 fpsLegacy 1500 enemies
67 fpsDOTS 4096 enemies
109.5 → 14.92msCPU frame time
691 → 4instanced batches

확인 항목

  • GameManager.instance에 상태, 입력, UI, 저장 책임이 집중되어 확장 비용이 증가.
  • Weapon.Update() switch 분기로 무기 추가와 테스트 비용이 증가.
  • UI Toolkit 텍스트 갱신과 GPU instancing 전환에서 실제 기기/렌더링 비용을 확인할 필요가 생김.

변경 기준

  • Enemy, Bullet, Drop, Wave, Damage Event를 DOTS 중심 slice로 분리.
  • RenderMeshIndirect는 URP 2D 궁합 문제 때문에 제외하고 DrawMeshInstanced 경로 유지.
  • UI는 변경 감지로 dirty 빈도를 줄이고, Android release/IAP/App Update 경계를 문서화.
비교 항목: Legacy/DOTS 구조, UI 갱신 비용, 렌더링 경로, Android 운영 경계.
비교 요약
병목전역 상태, Update 분기, UI 갱신 비용 확인.
분리Enemy/Bullet/Wave/Damage Event를 slice로 분리.
측정fps, CPU frame time, batch 수로 개선 전후 비교.
경로URP 2D와 맞지 않는 경로는 제외하고 유지 비용을 낮춤.
