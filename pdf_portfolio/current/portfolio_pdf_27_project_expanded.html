Ghost March / Performance Record

Legacy 기준본과 DOTS 재구성 비교

fps, CPU frame time, batch 수를 같은 비교 단위 안에 묶어 Legacy 기준본과 DOTS 재구성의 차이를 정리.

Legacy Baseline

대상1,500 enemies
성능약 9 fps
CPU109.5 ms frame time

DOTS Rebuild

대상4,096 enemies
성능약 67 fps
CPU14.92 ms frame time

Render / UI

Batch691 → 4 instanced batches
경로URP 2D와 맞지 않는 RenderMeshIndirect 제외
UIdirty 감지로 갱신 빈도 축소

확인 항목

  • GameManager.instance에 상태, 입력, UI, 저장 책임이 집중.
  • Weapon.Update() switch 분기로 무기 추가와 테스트 비용 증가.
  • UI Toolkit 텍스트 갱신과 GPU instancing 전환 비용을 실제 수치로 확인.

변경 기준

  • Enemy, Bullet, Drop, Wave, Damage Event를 DOTS 중심 slice로 분리.
  • 렌더링 경로는 성능 수치뿐 아니라 URP 2D 호환성과 유지 비용을 함께 판단.
  • Android release/IAP/App Update 경계는 운영 문서로 별도 관리.

Input System 간헐 입력 중단 추적

같은 코드에서도 키보드 입력이 간헐적으로 멈추는 문제를 코드 외부의 런타임/환경 상태까지 확인해 원인을 좁힘.

증상동일 코드/커밋에서도 키보드 입력이 간헐적으로 중단.
실패 시도ActionMap 강제 활성화, polling 전환, sceneLoaded, Domain Reload, Library 삭제.
원인터치스크린 노트북에서 Control Scheme이 Touch로 auto-switch.
조치Keyboard&Mouse scheme 강제, prefab default scheme 변경, auto-switch 해제.

피드백 반영 흐름

  • 개발일지와 플레이테스트로 유저 반응을 먼저 확인.
  • 입력, 조작감, 연출 피드백을 다음 빌드 작업 범위로 분리.
  • 팬게임 소재는 상업성보다 공개 개발과 유저 이해 근거로 배치.

기술 포인트

  • Input System 상태를 Inspector/환경 상태까지 추적.
  • DOTween 연출과 Aseprite 기반 리소스로 감성 재현에 집중.
  • GitHub Copilot은 반복 작업 보조로 사용하고 게임플레이 설계는 직접 판단.
